# Nộp bài Mạng máy tính - lớp CNTT 18-11

Repo dùng để nộp file Cisco Packet Tracer (`.pkt`) của môn Mạng máy tính.

> ⚠️ Repo để chế độ **Public**: ai có link cũng xem và tải được bài đã nộp.

## Quy ước đặt tên file

```
DeTai<số đề tài>_<TenDeTai>.pkt
```

Ví dụ: `DeTai26_PhanDoanMang_VLAN.pkt`

- Viết **không dấu**, không có dấu cách (dùng `_` để nối các từ).
- Mỗi nhóm nộp một file, do một bạn đại diện nộp.

## Cách nộp bài

1. Đăng nhập GitHub (chưa có tài khoản thì đăng ký tại [github.com](https://github.com)).
2. Đổi tên file theo quy ước ở trên.
3. Vào trang chính của repo, bấm **Add file → Upload files**, kéo file vào.
4. Kéo xuống dưới, bấm **Propose changes**.
5. Ở trang tiếp theo, bấm **Create pull request**, rồi bấm **Create pull request** thêm một lần nữa.
6. Bài được tính là đã nộp khi được **Merge**. Có thể xem trạng thái ở tab **Pull requests**.

## Lưu ý

- Kiểm tra file mở được bằng Packet Tracer trước khi nộp.
- Không sửa, xóa hay đổi tên file của nhóm khác.
- Nộp lại bản sửa thì tạo Pull request mới, ghi thêm "bản sửa" vào tiêu đề.
