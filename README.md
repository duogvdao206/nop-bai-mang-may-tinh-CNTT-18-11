# Nộp bài Mạng máy tính - lớp CNTT 18-11

Repo này dùng để nộp file Cisco Packet Tracer (`.pkt`) và báo cáo cho môn Mạng máy tính.

> ⚠️ Repo để chế độ **Public**: ai có link cũng xem và tải được bài đã nộp. Hãy chỉ nộp đúng file bài làm của nhóm mình.

---

## 1. Quy ước đặt tên file

```
Nhom<số nhóm>_CNTT-18-11.<đuôi file>
```

| Loại file | Ví dụ |
|---|---|
| File Packet Tracer | `Nhom5_CNTT-18-11.pkt` |
- Chỉ ghi **số nhóm** và **lớp**, không dùng dấu tiếng Việt, không có dấu cách.
- Mỗi nhóm chỉ cần **một bạn đại diện** nộp bài.
- Sai quy ước có thể bị yêu cầu nộp lại.

---

## 2. Cách nộp bài

**Bước 0: Chuẩn bị (làm một lần)**
- Tạo tài khoản tại [github.com](https://github.com) (Sign up) và xác nhận email.

**Bước 1: Đổi tên file** theo quy ước ở mục 1.

**Bước 2: Upload file**
1. Mở trang chính của repo này.
2. Bấm **Add file → Upload files**.
3. Kéo thả file vào khung, chờ thanh tải chạy xong.

**Bước 3: Gửi bài**
1. Kéo xuống phần **Commit changes**, ghi nội dung ngắn vào ô đầu, ví dụ: `Nhom5 - CNTT-18-11`.
2. Bấm **Propose changes**.
3. Ở trang tiếp theo (Comparing changes), bấm **Create pull request**.
4. Ghi tiêu đề dạng `Nhom5 - CNTT-18-11`, rồi bấm **Create pull request** một lần nữa.

**Bước 4: Kiểm tra**
- Vào tab **Pull requests** để xem bài của nhóm mình.
- Bài được tính là đã nộp khi người quản lý repo bấm **Merge**. Khi đó trạng thái chuyển sang **Merged** (màu tím) và file xuất hiện ở trang chính của repo.

---

## 3. Nộp lại bản sửa

Làm lại đúng các bước ở mục 2 và ghi thêm chữ **"bản sửa"** vào tiêu đề Pull request, ví dụ: `Nhom5 - CNTT-18-11 (bản sửa)`.

---

## 4. Lưu ý

- Kiểm tra file mở được bằng Packet Tracer trước khi nộp.
- File `.pkt` không xem trước được trên GitHub, muốn kiểm tra thì tải về máy rồi mở.
- Không sửa, xóa hay đổi tên file của nhóm khác.
- Nộp bài sớm, đừng để sát hạn vì bài cần được duyệt và merge.

---

## 5. Gặp lỗi?

| Vấn đề | Cách xử lý |
|---|---|
| Không thấy nút **Add file** | Chưa đăng nhập GitHub, hãy đăng nhập rồi mở lại link repo |
| Nút hiện **Commit changes** thay vì **Propose changes** | Hãy kiểm tra lại đã đăng nhập đúng tài khoản của mình chưa |
| Upload báo lỗi file quá lớn | Nén file hoặc giảm dung lượng, GitHub giới hạn 25 MB khi upload qua web |
| Pull request chưa được merge | Nhắn người quản lý repo hoặc kiểm tra bình luận trong Pull request xem có yêu cầu sửa gì không |
